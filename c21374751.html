When Social Media Helps vs Harms Mental Health

Big Idea

When Social Media Helps vs Harms Mental Health

Social media usage alone does not determine emotional wellbeing.
Instead, how people interact on social media plays a key role : higher interaction is associated with lower negative emotion, even at higher usage levels.

EXPLANATORY

TIME vs EMOTION

There is only a weak relationship between time and negative emotion.

This is an explanatory chart because it tests the relationship between usage time and emotion. A scatter plot is used because it is best for showing relationships between two variables. Colour (red/green) is used to make emotional outcomes instantly clear.

ggplot(social_clean, aes(x = Daily_Usage_Time, y = negative_emotion)) +
  geom_jitter(aes(color = factor(negative_emotion)), height = 0.05, alpha = 0.6) +
  geom_smooth(method = "lm", color = "black") +
  scale_color_manual(values = c("0" = "green", "1" = "red"),
                     labels = c("Positive/Neutral", "Negative")) +
  labs(
    title = "Does More Time Lead to Negative Emotion?",
    x = "Daily Usage (minutes)",
    y = "Negative Emotion",
    color = "Emotion Type"
  ) +
  theme_minimal()
`geom_smooth()` using formula = 'y ~ x'

INTERACTION EFFECT

Surprisingly, this shows that higher interaction is actually associated with slightly higher negative emotion.

This suggests that not all interaction is positive — it could include things like arguments, pressure, or over-engagement

This is the main explanatory chart as it directly supports the Big Idea. A bar chart is used because it compares two groups clearly. The data is aggregated to reduce noise and highlight the difference between interaction levels.

interaction_summary <- social_clean %>%
  group_by(interaction_level) %>%
  summarise(avg_negative = mean(negative_emotion))

p <- ggplot(interaction_summary, aes(x = interaction_level, y = avg_negative, fill = interaction_level)) +
  geom_col() +
  scale_fill_manual(values = c("High Interaction" = "green", "Low Interaction" = "red")) +
  labs(
    title = "Interaction VS  Negative Emotion",
    x = "Interaction Level",
    y = "Average Negative Emotion"
  ) +
  theme_minimal()

ggplotly(p)

Limitations

There are a few limitations in this analysis.

First, the social media data is self-reported, so it might not be fully accurate. People could be guessing how much time they spend online or how they feel, which can affect the results.

Also, the dataset doesn’t include any location data, so I couldn’t properly link it to the global happiness dataset. Because of that, the map is more for general context rather than a direct comparison.

Another thing is that emotions are simplified into categories like “happiness” or “anxiety”, which doesn’t really capture how complex emotions actually are in real life.

Finally, the data only shows relationships, not cause and effect. For example, even though higher interaction is linked with lower negative emotion, that doesn’t necessarily mean interaction is the reason for it.

Conclusion


Social media is not simply harmful or beneficial.
The data shows that interaction level plays a more important role than usage time.

Users who actively engage experience lower negative emotion, suggesting that meaningful interaction can offset potential negative effects of prolonged use.
